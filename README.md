# EIDOLON — Project #003: Matrix Rain

A procedural digital-rain simulation built with **Python and Pygame**.

Characters continuously fall down the screen in independent streams, each with its own speed, length, position, and character sequence.

This is **Project #003** in the EIDOLON 500+ project journey.

---

## 🎥 About

The goal of this project is to explore how simple text rendering and randomness can be transformed into a dynamic visual simulation.

Instead of drawing static text, the program creates dozens of independent streams that continuously move, mutate, reset, and interact with the visual composition.

The result is a constantly changing digital-rain effect.

---

## ✨ Features

- Procedural Matrix-style rain
- 55 independent character streams
- Randomized stream speeds
- Randomized stream lengths
- Random character generation
- Character mutation while falling
- Bright leading characters
- Multi-layer fading trails
- Random speed surges
- Procedurally generated audio
- Countdown sequence
- Start screen
- 60 FPS real-time animation
- No external Python dependencies besides Pygame
